## Pembukaan
Selama ini, setiap kali ingin membuat proyek WordPress baru, biasanya saya selalu  menggunakan AMP stack alias Apache Mysql dan PHP di sistem operasi linux favorit saya. Tapi belakangan ini saya sering mendengar istilah Docker. katanya, Docker bisa membuat alur development kita lebih rapi dan konsisten. Dengan niat memenuhi rasa penasaran sekaligus belajar hal baru saya memutuskan untuk mencoba. Di artikel ini, saya akan berbagi pengalaman pertama saya menjalankan WordPress lewat Docker di local server. prosesnya cukup cepat dan tidak memakan waktu terlalu lama.

Jujur, docker dalam laptop saya sudah terpasang secara sejak awal karena saya menggunakan sistem operasi Omarchy, jadi saya tidak akan membahas instalasi disini. tapi tenang pemasangan perangkat lunak ini tidaklah sulit. kalian tinggal ikuti panduan instalasi sesuai dengan sistem operasi yang kalian pakai. untuk dokumentasinya bisa kalian akses di link [ini](https://docs.docker.com/desktop).

## Pemasangan WordPress melalui Docker-Compose
Jadi bagaimana apakah kalian sudah berhasil memasang docker dalam mesin kalian?

Kalau sudah mari kita lanjut ke langkah selanjutnya, yakni konfigurasi agar docker bisa menjalankan WordPress. sebelumnya saya mau singgung sedikit bagaimana teknologi ini bekerja. docker adalah sebuah lingkungan development virtual dimana kalian bisa menjalankan sebuah program beserta komponen pendukungnya secara terisolasi, hal ini memastikan program/konfigurasi yang dibuat dapat berjalan secara konsisten disetiap jenis mesin. jadi ketika kita membuat wordpress di laptop kita kita bisa mengemasnya dan menjalankanya di komputer lain.

Untuk menjalankan wordpress sebagai docker kita akan menggunakan sebuah tool namanya docker compose, sebuah alat untuk menjalankan aplikasi multi container. Melalui tool ini kita akan menulis sebuah konfigurasi melalui file berekstensi YAML. Kemudian, melalui satu perintah kita akan membuat dan memulai aplikasinya dari file konfigurasi tersebut.

Tanpa basa-basi lagi mari kita mulai tutorialnya:


1. Buka Terminal/CMD kalain dan buat folder baru untuk wadah proyek kalian.
```
mkdir wp-docker # untuk nama folder terserah kalian aja.
```

2. Selanjutnya kalian bisa pindah ke direktori yang sudah kalian buat pakai perintah `cd #folder kalian` lalu buat sebuah file bernama "docker-compose.yml".

3. Di dalam file tersebut kalian bisa mulai menulis konfigurasinya.

```
version: '3.8'
services:
  wordpress:
    image: wordpress:latest
    ports:
      - "8080:80"
    environment:
      WORDPRESS_DB_HOST: db:3306
      WORDPRESS_DB_NAME: databasemu
      WORDPRESS_DB_USER: usernamemu
      WORDPRESS_DB_PASSWORD: passwordmu
    volumes:
      - wordpress_data:/var/www/html
    depends_on:
      - db
  db:
    image: mysql:5.7
    environment:
      MYSQL_ROOT_PASSWORD: my_root_password
      MYSQL_DATABASE: databasemu
      MYSQL_USER: usernamemu
      MYSQL_PASSWORD: passwordmu
    volumes:
      - db_data:/var/lib/mysql
volumes:
  wordpress_data:
  db_data:

```
***Penting!*** kalian jangan lupa untuk mengganti isian dari kolom nama database, nama username dan password ya..

4. Baiklah, sekarang kita tinggal menjalankan wordpress versi docker yang sudah kita konfigurasikan, untuk itu kalian bisa menjalankan perintah dibawah ini.

```
docker-compose up -d
```

5. Kalau aplikasinya sudah berjalan, buka browser kalian dan buka link `localhost:8080`, *voila* wordpress sudah terpasang di mesin kalian.
